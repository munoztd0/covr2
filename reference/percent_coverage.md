# Provide percent coverage of package

Calculate the total percent coverage from a coverage result object.

## Usage

``` r
percent_coverage(x, ...)
```

## Arguments

- x:

  the coverage object returned from
  [`package_coverage()`](https://munoztd0.github.io/covr2/reference/package_coverage.md)

- ...:

  additional arguments passed to
  [`tally_coverage()`](https://munoztd0.github.io/covr2/reference/tally_coverage.md)

## Value

The total percentage as a `numeric(1)`.
